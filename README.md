# Email Spam Detection using Naive Bayes

This project implements a machine learning-based spam detection system using:
- Multinomial Naive Bayes
- Complement Naive Bayes
- TF-IDF vectorization

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Results
- Accuracy: 97.9%
- F1-Score: 91.4%
- ROC-AUC: 0.988

## Dataset
SMS Spam Collection Dataset (UCI Repository)
